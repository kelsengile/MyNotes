# CSS - Cascading Style Sheets

Welcome! This is a self-paced course for learning CSS, the language used to style and lay out content on the web.

---

## What is CSS?

CSS lets you:
- Control the visual appearance of HTML elements (color, fonts, spacing)
- Build layouts using modern tools like Flexbox and Grid
- Make pages responsive across screen sizes and devices
- Add animations, transitions, and interactive visual effects
- Organize and reuse styles across a whole site
- Control positioning, stacking, and visibility of elements

## Who this is for

No prior experience needed — basic familiarity with HTML is helpful but not required.
