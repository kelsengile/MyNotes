# C++

Welcome! This is a self-paced course for learning C++, a powerful, high-performance language that extends C with object-oriented and modern programming features.

---

## What is C++?

C++ lets you:
- Write fast, efficient, low-level and high-level code in one language
- Use object-oriented programming with classes and inheritance
- Manage memory manually or with modern smart pointers
- Build games, system software, and performance-critical applications
- Use a large standard library (STL) for data structures and algorithms
- Take advantage of both procedural and object-oriented paradigms

## Who this is for

No prior experience needed, though basic familiarity with C concepts (variables, loops, functions) can help. No programming background required.
