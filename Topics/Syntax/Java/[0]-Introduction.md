# Java

Welcome! This is a self-paced course for learning Java, a widely-used, object-oriented programming language known for its portability, performance, and use in enterprise, Android, and large-scale systems.

---

## What is Java?

Java lets you:
- Write portable code that runs on any platform via the JVM ("write once, run anywhere")
- Build robust, object-oriented applications
- Develop enterprise software, backend services, and Android apps
- Work with strong typing and compile-time error checking
- Manage memory automatically through garbage collection
- Build large, maintainable systems using well-defined structure

## Who this is for

No prior experience needed — just basic comfort using a computer. No programming background required.
