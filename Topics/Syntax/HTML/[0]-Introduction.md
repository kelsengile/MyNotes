# HTML - HyperText Markup Language

Welcome! This is a self-paced course for learning HTML, the standard markup language used to structure content on the web.

---

## What is HTML?

HTML lets you:
- Structure content on a web page using elements and tags
- Build the skeleton that CSS styles and JavaScript makes interactive
- Create text, links, images, lists, tables, and forms
- Organize pages semantically for accessibility and SEO
- Embed media like audio, video, and iframes
- Build the foundation for any website or web app
