# Introduction to Algebra

This note covers the algebra foundations that show up throughout computer science — from analyzing algorithms to understanding machine learning models. It starts with core equation-solving and builds up to matrices and vectors, the language of linear algebra.

## Why Algebra Matters
Algebra is the toolkit for expressing and manipulating relationships between quantities — which is exactly what you're doing every time you write a formula, a loop condition, or a model. Linear algebra in particular underpins graphics, machine learning, and data analysis, so a solid grasp here pays off well beyond the math itself.
