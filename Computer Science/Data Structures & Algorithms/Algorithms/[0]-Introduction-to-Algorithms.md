# Introduction to Algorithms

This note covers the major families of algorithms you'll reuse across almost every programming problem — sorting, searching, and the core problem-solving strategies (greedy, divide-and-conquer, dynamic programming, backtracking) built on top of them. It assumes familiarity with the Data Structures and Complexity topics.

## Why Algorithms Matter
Data structures store your data — algorithms are what you do with it. The same problem can often be solved a dozen different ways, and the difference between a naive approach and a well-chosen algorithm can mean the difference between code that runs in milliseconds and code that never finishes. Learning these patterns also trains you to recognize which one applies to a new problem you haven't seen before.
