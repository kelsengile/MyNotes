# MyNotes
A personal, version-controlled collection of notes, ideas, learnings, and references — a single home for everything worth remembering.

## Structure
 
```
MyNotes/
├── Lessons/         # Notes and takeaways from courses, books, tutorials, and experiences
├── Ideas/           # Rough thoughts, brainstorms, and things to explore later
├── References/      # Cheatsheets, links, and quick-reference material
└── README.md
```
