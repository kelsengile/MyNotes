# Introduction to Visual Studio Code

Visual Studio Code (VS Code) is a free, lightweight source code editor developed by Microsoft. Unlike a full IDE that ships with everything built in for one language, VS Code starts minimal and becomes a fully-featured environment for almost any language or framework through its extensions marketplace — the same core editor can be turned into a Python IDE, a web development environment, or a C++ workspace depending on what you install.

This Topic covers VS Code's interface, its editing and navigation tools, and the extension and configuration system that lets it adapt to nearly any workflow. Debugging, source control, and remote development are also covered, since these built-in features are a large part of why VS Code has become one of the most widely used code editors in the industry.

## Why Learn Visual Studio Code?

- **Free and lightweight** — VS Code is free, open-source at its core, and starts up faster than most full IDEs, while still scaling up to handle large, complex projects.
- **Enormous extension ecosystem** — the Extensions Marketplace covers virtually every language, framework, and workflow, letting you build a custom setup rather than being locked into one vendor's toolchain.
- **Consistent across languages and platforms** — the same editor, keybindings, and interface work whether you're writing Python, JavaScript, C++, or Markdown, on Windows, macOS, or Linux.
- **Strong remote and container support** — Remote-SSH, Dev Containers, and WSL integration let you edit code that lives on a different machine as if it were local.
- **Widely adopted** — VS Code is the most-used code editor in industry surveys, so tutorials, extensions, and community support are abundant.
