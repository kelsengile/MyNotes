# Lesson 3 - Popular IDEs

## 3.1 Visual Studio Code

Visual Studio Code (VS Code) is a free, lightweight editor built by Microsoft that becomes a full IDE through its extension system. It supports nearly every programming language through extensions, has a built-in terminal and debugger, and is currently one of the most widely used tools among developers of all kinds because of how customizable and fast it is.

Stack Overflow's annual developer surveys have repeatedly ranked VS Code as the most-used development environment worldwide, largely because the same install can be configured for web development, Python, C++, or even writing documentation, just by adding extensions.

---

## 3.2 JetBrains IDEs

JetBrains makes a family of IDEs specialized per language — IntelliJ IDEA for Java and Kotlin, PyCharm for Python, WebStorm for JavaScript, CLion for C/C++, and others. They share a common interface and are known for deep, language-specific features like powerful refactoring tools and highly accurate code analysis, at the cost of being heavier applications than a general-purpose editor.

| JetBrains IDE | Primary language(s) |
|---|---|
| IntelliJ IDEA | Java, Kotlin |
| PyCharm | Python |
| WebStorm | JavaScript, TypeScript |
| CLion | C, C++ |
| Rider | C#, .NET |

---

## 3.3 Visual Studio

Not to be confused with VS Code, Visual Studio is Microsoft's full, heavyweight IDE, mainly used for C#, C++, and .NET development on Windows. It includes an advanced visual debugger, GUI designers for building desktop applications, and tight integration with the .NET ecosystem.

A quick way to avoid confusing the two: **Visual Studio** ships as a large, Windows-first installer with GUI designers baked in; **VS Code** is a small, cross-platform download that starts nearly empty and grows through extensions.

---

## 3.4 Other Notable IDEs

- **Xcode** — Apple's official IDE for building iOS, macOS, and other Apple-platform apps in Swift or Objective-C.
- **Eclipse** — a long-standing, highly extensible IDE historically popular for Java development.
- **Android Studio** — the official IDE for Android app development, built on the same platform as the JetBrains IDEs.
- **Cloud/browser-based IDEs** — tools that run entirely in a browser with no local install, covered further in a later lesson.

There is no single "best" IDE — the right choice depends on the language and platform you're working with, which is explored more in the final lesson of this Topic.

| If you're building... | A common starting point is... |
|---|---|
| An iOS or macOS app | Xcode |
| An Android app | Android Studio |
| A large legacy Java codebase | Eclipse or IntelliJ IDEA |
| A quick script in any language | VS Code |
