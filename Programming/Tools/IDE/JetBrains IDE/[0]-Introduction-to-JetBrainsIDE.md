# Introduction to JetBrains IDEs

JetBrains makes a family of language-specific integrated development environments — IntelliJ IDEA (Java/Kotlin), PyCharm (Python), WebStorm (JavaScript/TypeScript), Rider (.NET), CLion (C/C++), GoLand (Go), and others — that all share the same underlying platform, interface, and core feature set. Learning one JetBrains IDE transfers almost directly to the others, since the keymaps, tool windows, and refactoring engine look and behave the same regardless of which language you're working in.

This Topic covers the shared JetBrains platform: the interface every one of these IDEs is built on, the code intelligence and refactoring tools that make them popular with professional developers, and the debugging and version control workflows that stay consistent across the whole product line. Language-specific features are mentioned where relevant, but the focus is on what makes the JetBrains experience distinct from a general-purpose code editor.

## Why Learn a JetBrains IDE?

- **Deep code intelligence** — JetBrains IDEs analyze your entire project, not just the open file, enabling accurate autocomplete, navigation, and refactoring that lighter editors can't match.
- **Powerful refactoring tools** — renaming a symbol, extracting a method, or changing a function signature updates every usage across the project automatically and safely.
- **One interface, many languages** — once you're comfortable in one JetBrains IDE, switching to another for a different language requires very little relearning.
- **Built-in tooling** — a debugger, version control integration, a database client, and a terminal are all included out of the box, reducing the number of separate tools you need.
- **Industry-standard for many stacks** — IntelliJ IDEA and Android Studio (built on the same platform) are the de facto standard for Java, Kotlin, and Android development.
