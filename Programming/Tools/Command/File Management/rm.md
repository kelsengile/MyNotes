# rm (remove)

`rm` deletes files and, with the right flag, entire directories. It's one of the most powerful — and most dangerous — commands in this Topic, since there's no built-in recycle bin.

Download: [https://man7.org/linux/man-pages/man1/rm.1.html](https://man7.org/linux/man-pages/man1/rm.1.html)

---

## What Is rm?

Files deleted with `rm` don't go to a trash folder — they're unlinked from the filesystem immediately, and recovering them afterward is difficult or impossible without specialized tools. This makes `rm` a command worth double-checking before pressing Enter.

---

## Core Commands

```bash
rm file.txt                 # Delete a single file
rm file1.txt file2.txt      # Delete multiple files
rm -r folder/                # Recursively delete a folder and everything inside it
rm -i file.txt                # Prompt for confirmation before deleting
rm -f file.txt                # Force delete, suppressing prompts and "file not found" errors
```

---

## A Word of Caution

```bash
rm -rf /some/path
```

`-r` (recursive) combined with `-f` (force, no prompts) deletes an entire folder tree instantly with no confirmation and no undo. Always double-check the path — especially that there's no typo turning a relative path into an absolute one — before running `rm -rf` on anything.

---

## Example Walkthrough

```bash
rm -i old_notes.txt
rm -r build/
```

Deletes a single file with a confirmation prompt as a safety check, then removes an entire `build` folder generated by a compiler, which is safe to regenerate at any time.
