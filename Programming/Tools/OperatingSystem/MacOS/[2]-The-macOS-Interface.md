# Lesson 2 - The macOS Interface

## 2.1 The Menu Bar And Dock

macOS organizes its interface around two fixed elements that are almost always visible: the **menu bar** at the top of the screen and the **Dock** at the bottom (or side).

```
 ▓ File Edit View Go Window Help  🔍 🔋 📶 🕐 Sun 2:14 PM        ← Menu Bar
┌──────────────────────────────────────────────────────────────┐
│                                                                │
│                        (Desktop / Windows)                    │
│                                                                │
└──────────────────────────────────────────────────────────────┘
      🖥️  📁  ✉️  🌐  🎵  📷   ...                                 ← Dock
```

- The **menu bar** always shows the Apple menu (), the name of the currently active app, and that app's menus. On the right side sits the **menu bar extras** (Wi-Fi, battery, clock, Control Center) — small icons for quick access to system status and settings.
- The **Dock** holds shortcuts to frequently used apps and shows a small dot under any app that's currently running. You can permanently add an app by dragging it into the Dock, and temporarily see any open app there even if it isn't "pinned."
- The line separating pinned apps from open-but-unpinned apps (and the Trash) is called the **Dock divider**.

## 2.2 Finder And The File System

**Finder** is macOS's file manager — the equivalent of File Explorer on Windows. It's always running (you'll notice its smiling-face icon is the leftmost item in the Dock and can't be removed) and is how you browse files, folders, and connected drives.

A typical Finder window looks like this:

```
┌───────────────────────────────────────────────────┐
│ ● ● ●   Documents                     🔍 Search    │
├───────────┬─────────────────────────────────────────┤
│ Favorites │  📁 Projects        📁 Photos            │
│  AirDrop  │  📄 Resume.pdf      📄 Notes.md          │
│  Desktop  │                                          │
│  Docs     │                                          │
│  Downloads│                                          │
│  iCloud   │                                          │
└───────────┴─────────────────────────────────────────┘
```

The left-hand **sidebar** gives one-click access to common locations (we'll cover the Home folder structure it points to in Lesson 3). Finder windows can be viewed as icons, a list, columns, or a "gallery" of large previews — switchable from the View menu or the toolbar.

## 2.3 Spotlight Search

**Spotlight** is macOS's built-in search tool, opened with **⌘ (Command) + Space** from anywhere. It searches far beyond file names:

- Launching applications ("type `Calculator`, press Return")
- Doing quick math (`234 * 18`) or unit conversions (`10 km in miles`)
- Looking up word definitions
- Searching file contents, not just file names
- Searching the web and showing quick facts

Because it's so fast, many longtime Mac users treat Spotlight as their primary app launcher instead of digging through the Dock or Applications folder.

## 2.4 Mission Control And Spaces

**Mission Control** (opened with a three- or four-finger swipe up on the trackpad, or the F3 key) gives you a bird's-eye view of everything currently open:

```
Mission Control View:
┌─────────┐ ┌─────────┐ ┌─────────┐
│ Desktop1│ │ Desktop2│ │  Full-  │
│ (Mail,  │ │ (Xcode) │ │ Screen  │
│ Safari) │ │         │ │  App    │
└─────────┘ └─────────┘ └─────────┘
      ▲ drag windows between these "Spaces" ▲
```

**Spaces** are separate virtual desktops. Instead of piling every window onto one screen, you can dedicate one Space to email and browsing, another to coding, and another to a full-screen app — then switch between them with **Control + Left/Right Arrow**. This is especially useful on laptops with smaller screens, where physical screen space is limited but virtual space isn't.
