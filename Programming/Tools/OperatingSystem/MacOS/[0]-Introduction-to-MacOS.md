# Introduction to macOS

macOS is Apple's desktop and laptop operating system, built on a Unix foundation and designed to work exclusively on Apple's own Mac hardware. It's known for its polished, consistent interface, tight integration with other Apple devices (iPhone, iPad, Apple Watch), and a Unix-based terminal underneath that makes it a popular choice among software developers despite being a consumer-focused, closed-hardware system.

This Topic covers macOS's interface — the menu bar, Dock, and Finder — its file system and iCloud integration, and the system settings and built-in apps that make up the everyday experience. It also covers the Terminal and Homebrew, since macOS's Unix underpinnings are a major reason it's so widely used for development work.

## Why Learn macOS?

- **A favorite platform among developers** — its Unix foundation means most command-line tools, scripting languages, and server-like environments behave the same way they would on Linux.
- **Required for Apple platform development** — building and shipping an iOS, iPadOS, or watchOS app requires Xcode, which only runs on macOS.
- **Seamless hardware and software integration** — because Apple controls both, features like Handoff, Universal Clipboard, and Continuity Camera work with little to no setup.
- **Consistent design language** — apps across macOS tend to follow the same interface conventions, which makes new software easier to learn quickly.
- **Strong for creative and technical work alike** — video editing, audio production, and software development are all well-supported by macOS's ecosystem of first-party and third-party tools.
