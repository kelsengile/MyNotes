# Lesson 4 - System Settings And Customization

## 4.1 System Settings Overview

**System Settings** (called System Preferences before macOS Ventura) is the control panel for the entire operating system. You can open it from the Apple menu () or by searching "System Settings" in Spotlight. It's organized into categories in a sidebar:

```
┌────────────────┬───────────────────────────────┐
│ 🔍 Search       │                               │
│ Wi-Fi           │      (Selected panel's         │
│ Bluetooth       │       settings appear here)    │
│ Network         │                               │
│ Displays        │                               │
│ Sound           │                               │
│ Users & Groups  │                               │
│ Privacy & Sec.  │                               │
│ ...             │                               │
└────────────────┴───────────────────────────────┘
```

Rather than memorizing every location, the search bar at the top is usually the fastest way to find a specific setting — typing "battery" will jump straight to battery-related options even if you're not sure which category they live under.

## 4.2 Managing Users And Permissions

macOS supports multiple user accounts on one Mac, each with its own Home folder, files, and preferences — useful for a shared family computer or a work machine with separate profiles. Accounts fall into a few types:

| Account Type | Can Install Apps / Change System Settings | Typical Use |
|---|---|---|
| Administrator | Yes | The main/owner account |
| Standard | No (needs admin password) | Family members, guests |
| Guest | No, and resets on logout | Temporary/shared use |

Permissions extend beyond user accounts, too. Starting with macOS's stronger privacy protections, apps must explicitly request access to sensitive resources — your camera, microphone, location, contacts, or files in Documents/Desktop. You'll see a system prompt the first time an app needs one of these, and you can review or revoke any of them later under **Privacy & Security**.

## 4.3 Keyboard Shortcuts And Trackpad Gestures

Learning a handful of shortcuts and gestures dramatically speeds up everyday use of macOS:

| Shortcut | Action |
|---|---|
| ⌘ + Space | Open Spotlight |
| ⌘ + Tab | Switch between open apps |
| ⌘ + Q | Quit the current app |
| ⌘ + W | Close the current window |
| ⌘ + Shift + 4 | Take a screenshot of a selected area |
| ⌘ + C / ⌘ + V | Copy / Paste |
| ⌘ + Z | Undo |

| Trackpad Gesture | Action |
|---|---|
| Two-finger scroll | Scroll up/down/sideways |
| Two-finger swipe left/right | Navigate back/forward |
| Three-finger swipe up | Mission Control |
| Pinch with thumb + 3 fingers | Show Desktop |
| Double-tap with two fingers | Smart zoom |

Both shortcuts and gestures are customizable under **System Settings → Keyboard** and **System Settings → Trackpad**, so power users often remap them to fit their own habits.

## 4.4 Accessibility Features

macOS includes a broad set of built-in accessibility tools, grouped under **System Settings → Accessibility**, designed so the system can be adapted to a wide range of needs rather than requiring third-party software:

- **VoiceOver** — a full screen reader that describes what's on screen aloud and lets you navigate entirely without seeing the display.
- **Zoom** — magnifies part or all of the screen.
- **Display accommodations** — increased contrast, reduced transparency, and color filters for various types of color blindness.
- **Voice Control** — lets you operate the entire Mac, including clicking and typing, using only spoken commands.
- **Switch Control** — allows the Mac to be operated using adaptive switch hardware instead of a keyboard or mouse, for users with limited mobility.

These aren't niche extras — they're deeply integrated, and some (like Zoom or increased contrast) are commonly used by people without disabilities simply for comfort or preference.
