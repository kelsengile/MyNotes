# Lesson 2 - The Windows Interface

## 2.1 The Desktop, Taskbar, And Start Menu

The Windows interface centers on three elements: the **Desktop**, the **Taskbar**, and the **Start menu**.

```
┌────────────────────────────────────────────────────────────┐
│                                                              │
│                     (Desktop / open windows)                │
│                                                              │
├────────────────────────────────────────────────────────────┤
│  ⊞  🔍  📁  🌐  ✉️            📶 🔊 🔋  4:12 PM  ▲          │  ← Taskbar
└────────────────────────────────────────────────────────────┘
    ↑ Start button opens the Start menu
```

- The **Desktop** is the background workspace where shortcuts and files can be placed, and where open app windows appear.
- The **Taskbar** sits (by default) at the bottom of the screen, showing pinned and running apps, a search box, and a **system tray** on the right with icons for network, volume, battery, and the clock.
- The **Start menu**, opened by clicking the Windows logo (⊞) or pressing the **Windows key**, gives access to installed apps, pinned tiles/apps, and power options (Sleep, Restart, Shut Down).

Windows 11 changed the default Taskbar layout to center the Start button and icons (previously left-aligned in Windows 10 and earlier), though this can be changed back in Settings.

## 2.2 File Explorer

**File Explorer** (formerly "Windows Explorer") is the built-in file manager, opened via the folder icon in the Taskbar or the **Windows key + E** shortcut.

```
┌───────────────────────────────────────────────────┐
│ ← → ↑   This PC > Documents          🔍 Search     │
├───────────┬─────────────────────────────────────────┤
│ Quick     │  📁 Projects        📁 Photos            │
│ access    │  📄 Resume.docx     📄 Notes.txt         │
│ This PC   │                                          │
│  C:       │                                          │
│  D:       │                                          │
│ Network   │                                          │
└───────────┴─────────────────────────────────────────┘
```

The left sidebar includes **Quick access** (frequently or recently used folders), **This PC** (showing all connected drives by letter — covered in Lesson 3), and any mapped network locations. File Explorer supports several view modes (icons, list, details, tiles) and, since Windows 11, a simplified ribbon-style toolbar with common actions like cut, copy, rename, and share.

## 2.3 Windows Search

**Windows Search**, accessible from the search box in the Taskbar or by pressing the **Windows key** and simply typing, indexes files, settings, and installed apps to return fast results as you type:

- Launching apps by name ("type `notepad`, press Enter")
- Finding files by name or, for many file types, by content
- Jumping directly into a Settings page ("type `bluetooth`" to open Bluetooth settings)
- Web search results (via Bing) when local results don't fully answer the query

Because it indexes in the background, search stays fast even on machines with large numbers of files, though a freshly created file may take a short time to appear in results while the index catches up.

## 2.4 Virtual Desktops And Task View

**Task View** (the icon next to the search box in the Taskbar, or **Windows key + Tab**) shows every open window at once and lets you manage **virtual desktops** — separate workspaces you can switch between without closing anything:

```
Task View:
┌──────────┐  ┌──────────┐  ┌──────────┐
│ Desktop 1│  │ Desktop 2│  │  + New   │
│ (Browser,│  │ (Code    │  │ Desktop  │
│  Mail)   │  │  Editor) │  │          │
└──────────┘  └──────────┘  └──────────┘
```

You can create a new virtual desktop, drag windows between them, and switch quickly with **Ctrl + Windows key + Left/Right Arrow**. This is functionally similar to Spaces on macOS (Lesson 2 of the macOS Topic) — a way to separate different tasks (work, personal browsing, a full-screen game) onto distinct virtual screens rather than crowding one desktop with every open window.
