# Introduction to Windows

Windows is Microsoft's operating system and the most widely used desktop OS in the world, running on hardware from a huge range of manufacturers rather than a single vendor. Its broad hardware compatibility, long history of backward compatibility, and dominance in business and enterprise environments have made it the default choice for a large share of the world's PCs, gaming machines, and corporate workstations.

This Topic covers the Windows interface — the Desktop, Taskbar, and File Explorer — its file system and storage model, and the system settings and built-in tools that make up everyday use. It also covers Windows' command-line tools (Command Prompt, PowerShell, and Windows Terminal) and WSL, since these are central to how Windows is used for software development.

## Why Learn Windows?

- **The most common desktop OS** — Windows holds the largest share of desktop and laptop operating systems worldwide, making it essential general computer literacy.
- **Dominant in business and enterprise** — most corporate environments standardize on Windows, along with Microsoft 365 and Active Directory-based IT management.
- **The primary platform for PC gaming** — the overwhelming majority of PC games are built and optimized for Windows first.
- **Broad hardware compatibility** — Windows runs on an enormous range of hardware from many different manufacturers, unlike operating systems tied to one vendor's devices.
- **A capable development platform** — with PowerShell, Windows Terminal, and WSL2, Windows now supports Linux-style development workflows directly, alongside its native .NET and Visual Studio tooling.
