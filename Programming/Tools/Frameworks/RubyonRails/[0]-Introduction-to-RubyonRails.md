Ruby on Rails is a full-stack web framework built on the philosophy of convention over configuration. By agreeing on sensible defaults for file locations, naming, and structure, Rails lets you build complete applications with remarkably little code.

Rails has powered many well-known startups and products. This Topic covers Ruby essentials for Rails, routing, controllers, views, Active Record, validations and associations, authentication, Hotwire, testing, and deployment.

### Why Study Ruby on Rails?

- **Very fast to build with** — generators and conventions turn ideas into working apps quickly.
- **Complete framework** — database, mailers, file storage, jobs, and real-time features are included.
- **Teaches lasting web patterns** — MVC, REST, migrations, and testing practices popularized by Rails appear everywhere.
- **Proven in production** — used by many successful products that are built and maintained by small teams.

### Ruby on Rails At A Glance

| Attribute | Details |
|---|---|
| Language | Ruby |
| Type | Full-stack web framework |
| Philosophy | Convention over configuration |
| Best for | Startups, MVPs, content and SaaS products |
| Pairs well with | PostgreSQL, Hotwire, Sidekiq, RSpec |
