React is a JavaScript library for building user interfaces out of small, reusable pieces called components. Instead of manually updating the page whenever data changes, you describe what the interface should look like for a given state, and React works out the minimal set of changes needed to keep the screen in sync.

React is deliberately focused: it handles the view layer and leaves routing, data fetching, and project structure to the wider ecosystem. This Topic teaches React from your first component through hooks, state, routing, data fetching, performance, and modern features like Server Components, so you can read and build real React applications.

### Why Study React?

- **It dominates frontend job listings** — React skills open the door to a huge share of web development roles.
- **It is the foundation for other tools** — Next.js, React Native, and many UI libraries are built directly on React's ideas.
- **Components make large UIs manageable** — splitting an interface into reusable pieces keeps big applications understandable.
- **The ecosystem is enormous** — routing, forms, data fetching, testing, and UI kits all have mature, well-documented options.
