React Native is a framework for building native iOS and Android apps using React and JavaScript. Your components render as real native views rather than web elements, so apps look and feel like they belong on the device while sharing most of their code across platforms.

If you already know React, React Native lets you reuse those skills on mobile. This Topic covers core components, styling with Flexbox, navigation, state, networking, storage, native device features, animations, the new architecture, testing, and publishing to the app stores.

### Why Study React Native?

- **Reuse your React skills** — web developers can move into mobile without learning a new language.
- **One codebase for two platforms** — share logic and UI across iOS and Android.
- **Fast iteration** — Fast Refresh and Expo make testing on a real device quick.
- **Backed by a large community** — widely adopted by companies of all sizes.

### React Native At A Glance

| Attribute | Details |
|---|---|
| Language | JavaScript / TypeScript |
