# HTML

[⬅ Back to README](../../../README.md)

Welcome! This is a self-paced course for learning HTML (HyperText Markup Language), the foundational markup language that structures and gives meaning to every page on the web.

---

## What is HTML?

HTML lets you:
- Structure web page content using elements and semantic tags
- Build forms that collect and validate user input
- Embed images, audio, video, and other media
- Create accessible content usable by screen readers and assistive technology
- Organize content for search engines (SEO)
- Build tables, lists, and structured data layouts
- Embed external content with iframes and objects
- Define custom, reusable components with Web Components
- Lay the structural foundation that CSS styles and JavaScript brings to life
