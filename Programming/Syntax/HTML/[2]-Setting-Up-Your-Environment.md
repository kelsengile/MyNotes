# Lesson 2 - Setting Up Your Environment

## 2.1 Choosing a Code Editor

You can write HTML in any plain-text editor, but a code editor makes life easier with syntax highlighting, autocompletion, and error detection. Popular free choices:

- **Visual Studio Code (VS Code)** — the most widely used, with a huge extension ecosystem.
- **Sublime Text** — lightweight and fast.
- **WebStorm** — a full IDE, geared toward larger projects.

For this course, any of these work fine. VS Code is recommended if you're unsure.

---

## 2.2 Choosing a Browser & DevTools

You'll also need a modern browser: Chrome, Firefox, Edge, or Safari all work well. Each ships with **Developer Tools** (DevTools) — press `F12` or right-click a page and choose "Inspect" to open them.

DevTools let you:

- Inspect the live HTML structure of any page.
- See which CSS rules are applied to an element.
- View console errors and logs.
- Test how a page looks on different screen sizes.

Getting comfortable with DevTools early will make debugging HTML much faster throughout this course.

---

## 2.3 Creating Your First HTML File

HTML files use the `.html` extension. Create a new file named `index.html` and open it directly in your browser (double-click it, or drag it into a browser window) to see it render.

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
  </body>
</html>
```

Save the file, open it in your browser, and you should see "Hello, World!" displayed. We'll break down exactly what each of these tags means in the next lesson.
