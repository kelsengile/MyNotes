# JavaScript

Welcome! This is a self-paced course for learning JavaScript, the programming language of the web, used to build interactive websites, web apps, servers, and more.

---

## What is JavaScript?

JavaScript lets you:
- Add interactivity and dynamic behavior to web pages
- Manipulate and respond to events in the browser (DOM)
- Build front-end applications with modern frameworks
- Write server-side code using Node.js
- Work with APIs, data, and asynchronous operations
- Build full-stack applications from browser to backend
