# Data Science


Welcome! This is a self-paced course for learning Data Science, the practice of extracting insight from data through statistics, visualization, and machine learning.

---

## What is Data Science?

Data Science lets you:
- Collect, clean, and wrangle data from files, databases, APIs, and the web
- Explore data with descriptive statistics and visualizations
- Apply probability and statistical inference to draw sound conclusions
- Build and evaluate machine learning models, from regression to deep learning
- Work with text through natural language processing and modern language models
- Deploy models as APIs and monitor them in production (MLOps)
- Work with big data tools and SQL at scale
- Communicate findings clearly, ethically, and reproducibly
