# Lesson 47 - Cloud Certifications & Career Paths

## 47.1 Why Get Certified?

Cloud certifications validate specific, provider-recognized knowledge and can help with job applications, salary negotiation, and structuring your own learning — a certification's exam guide is effectively a well-organized syllabus of what's considered important to know. That said, certifications are a supplement to real hands-on experience, not a replacement for it; the concepts practiced throughout this course (deploying real infrastructure, writing IaC, debugging actual failures) build the deeper competence that certification exams only sample.

---

## 47.2 Popular Certifications

Each major provider offers a tiered certification path, roughly progressing from foundational to associate to professional/specialty:

- **AWS** — Cloud Practitioner (foundational) → Solutions Architect / Developer / SysOps Administrator (Associate) → Solutions Architect Professional / DevOps Engineer Professional, plus specialty certifications (Security, Networking, Machine Learning, etc.).
- **Azure** — Azure Fundamentals (AZ-900) → Azure Administrator / Azure Developer (Associate) → Solutions Architect Expert / DevOps Engineer Expert.
- **GCP** — Cloud Digital Leader (foundational) → Associate Cloud Engineer → Professional Cloud Architect / Professional Cloud DevOps Engineer, plus specialty tracks.
- **Vendor-neutral** — the **Certified Kubernetes Administrator (CKA)** and related CNCF certifications, useful regardless of which cloud provider you use.

A reasonable starting point for most learners is a provider's foundational certification, followed by an Associate-level certification matching your role (e.g. Solutions Architect for infrastructure-focused roles, Developer for application-focused roles).

---

## 47.3 Career Paths in Cloud

Cloud skills open into several distinct but overlapping career paths:

- **Cloud/DevOps Engineer** — builds and maintains infrastructure, CI/CD pipelines, and automation (Lessons 20–29).
- **Site Reliability Engineer (SRE)** — focuses on reliability, observability, and incident response for production systems (Lessons 30–32, 44).
- **Cloud Security Engineer** — specializes in IAM, encryption, compliance, and threat detection (Lessons 33–36).
- **Cloud Solutions Architect** — designs overall system architecture, balancing the Well-Architected pillars (Lesson 46) for specific business needs.
- **Cloud Application Developer** — builds application features on top of cloud services (compute, storage, databases, serverless).

Having completed this course, you now have a working vocabulary and mental model across all of these areas — the natural next step is building real projects (deploying an actual application with IaC, setting up a real CI/CD pipeline, configuring real monitoring) to turn this conceptual foundation into practical, demonstrable experience.
