# Lesson 4 - Prototyping & Game Design Documents

## 4.1 Why Prototype First?

A prototype is a rough, fast, disposable version of your game built to answer one question: **is this fun?** Prototyping before committing to final art or polished code saves enormous time, because it's far cheaper to throw away a gray-box level than a fully textured, animated one. Good prototypes:

- Use placeholder art (cubes, colored squares, default shapes).
- Focus on one core mechanic at a time.
- Are expected to be rebuilt or thrown away, not shipped.

---

## 4.2 What Is a Game Design Document (GDD)?

A **Game Design Document** is a living reference that captures what your game is and how it plays, so that you (and any collaborators) stay aligned as the project grows. It doesn't need to be long — a one-page GDD for a small prototype is often more useful than a 40-page document nobody reads.

---

## 4.3 Core Sections of a GDD

A lightweight GDD typically includes:

- **High concept** — one or two sentences describing the game.
- **Core gameplay loop** — the repeating cycle of actions the player performs (e.g. explore → fight → loot → upgrade → repeat).
- **Controls** — the input scheme.
- **Win/lose conditions** — how the player succeeds or fails.
- **Scope** — what's in, and just as importantly, what's explicitly *out* of the first version.
- **Reference games** — existing titles that inspire the tone, mechanics, or feel.

---

## 4.4 From Paper Prototype to Digital Prototype

Not every idea needs code to test. A **paper prototype** (index cards, a board, dice) can validate a turn-based or systems-driven idea in an afternoon. Once the core loop feels promising:

1. Build the smallest possible digital version — one mechanic, one test scene.
2. Playtest it yourself, then with someone else who hasn't seen it.
3. Ask: does this loop feel good *before* any art or story is added? If not, iterate on the mechanic before investing further.
4. Only after the core loop is validated should you move on to building out the broader systems covered in the rest of this course.
